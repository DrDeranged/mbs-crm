`approved-structure-exceptions.json` is the machine-readable, fixture-specific
exception list: 36 page/width/role keys, exact old/new descriptor spans and exact
before/after inventories of separately inventoried controls. It is frozen from
the differences explicitly approved by the user, NOT regenerated by the runner.

The checker preserves every descriptor outside these spans in sequence, fails
if a span's baseline no longer matches, and compares the expected edited sequence
to the entire freshly captured sequence. It also rejects extra controls placed
inside an approved container. It does not whitelist arbitrary contact selectors,
drop all links, ignore accessible names globally, or normalize new failures away.

ticket/local-storage sandbox, and disable external delivery as the sandbox does.
The before build must be rebuilt from the **complete** baseline source checkout
(including root TypeScript configuration and shared packages), not copied from
the refreshed web directory. Configure installed workspace dependencies and
